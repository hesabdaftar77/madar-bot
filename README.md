# مدار پرو (Madar Pro) — ربات تلگرام، مرحله ۱

## متغیرهای محیطی (در Railway → Variables)
| نام | مقدار |
|---|---|
| BOT_TOKEN | توکن ربات از @BotFather |
| ALLOWED_IDS | شناسه عددی ۴ نفر با ویرگول؛ **اولی = مدیر اصلی** (مثلاً 111,222,333,444) |
| DB_PATH | /data/madar.db |

## راه‌اندازی
1. کد را در یک ریپوی GitHub (Private) بگذار و در Railway «Deploy from GitHub» بزن.
2. در سرویس، یک **Volume** بساز و روی مسیر `/data` وصل کن (بدون آن، داده با هر دیپلوی پاک می‌شود).
3. اول ALLOWED_IDS را خالی بگذار، به ربات /start بزن؛ شناسه عددی‌ات را نشان می‌دهد. همین کار را هر چهار نفر انجام دهند، بعد مقدار را در Variables بگذار و سرویس را Restart کن.
4. هر نفر یک‌بار /start بزند (برای اینکه ربات بتواند به او پیام بدهد).

## اجرا روی کامپیوتر (برای تست)
```
pip install -r requirements.txt
set BOT_TOKEN=...   (ویندوز)      export BOT_TOKEN=...  (لینوکس/مک)
set ALLOWED_IDS=123456789
set DB_PATH=madar.db
python bot.py
```

## امکانات این مرحله
افزودن مشتری و فایل (فرم مرحله‌ای)، فایل‌یاب با درصد و دلیل، پیشنهاد مشتری هنگام ثبت فایل،
تشخیص فایل تکراری، جستجو، حذف با تأیید، بستن/بازکردن فایل، وظایف با یادآور، لیگ اعضا،
پیام به دفتر، لاگ فعالیت‌ها، پشتیبان خودکار شبانه (ساعت ۳ تهران) به تلگرام مدیر، دستور /backup.
